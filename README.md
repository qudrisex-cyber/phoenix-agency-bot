# PHOENIX AGENCY Bot

Telegram-бот для приветствия новых пользователей и связи с менеджером.

## Переменная окружения

`BOT_TOKEN` — токен Telegram-бота из BotFather.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Пользователи, которые запускают бота, сохраняются в локальную SQLite-базу. База исключена из Git.
